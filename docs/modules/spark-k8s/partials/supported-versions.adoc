- 4.2.0 (Hadoop 3.5.0, Scala 2.13, Python 3.14, Java 25)
- 4.1.3 (Hadoop 3.4.3, Scala 2.13, Python 3.12, Java 21) (LTS)
- 4.1.2 (Hadoop 3.4.3, Scala 2.13, Python 3.12, Java 21) (Deprecated)

All Spark images also include the HBase connectors library built against HBase 2.6.7.
As of today (26th October 2026) there is no official release of these connectors with Spark 4 support.
The version included in the SDP Spark images is built from https://github.com/stackabletech/hbase-connectors/commit/07f5791c4921e471d328c8ce5f760ac72f0090cb[07f5791] on the `master` branch.
